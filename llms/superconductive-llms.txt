# Superconductive / Great Expectations (GX)

> Superconductive Inc. is the company behind Great Expectations (GX), an open-source (Apache-2.0) data quality framework. Teams declare "Expectations" about how data should behave, and GX Core — the Python library at the heart of the platform — validates batches of data against them, generates human-readable Data Docs, and integrates with modern data-stack tooling. GX is distributed primarily as a Python package rather than a hosted REST API. Backed by Index Ventures.

## Product
- [GX Core (docs)](https://docs.greatexpectations.io/docs/): The Great Expectations Python library — the engine of the data quality platform.
- [GX Cloud](https://greatexpectations.io/cloud/): Managed SaaS offering (wound down; open-source library is the supported surface).
